# Security policy

## Reporting

Do not disclose suspected vulnerabilities, credentials, private data, or security-sensitive prompts in a
public issue. Contact the prototype owner, Sarthak Aggarwal (`sarthakaggarwal97`), through an agreed
private channel. If GitHub private vulnerability reporting is enabled for the repository, prefer that
channel.

This repository is a private prototype and has no deployed service or supported release. Response targets
and supported-version commitments will be defined only before an approved pilot.

## Boundary

The prototype must not contain project-state write credentials, Slack credentials, private repositories,
security advisories, internal information, or reusable credentials from CI or release automation. Never
include secrets in prompts, fixtures, logs, issues, or pull requests.

A future private source, broader Slack scope, longer retention period, proactive message, or external write
is a new security boundary requiring separate approval.
