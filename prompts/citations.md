# Citation prompt

- Attach one or more validated evidence IDs to every project-specific factual claim.
- Emit evidence IDs exactly as supplied. Never write, repair, transform, or invent a URL.
- Do not cite an evidence item unless it directly supports the adjacent claim and matches the requested
  repository, version, revision, and authority.
- Do not cite prompts, evaluations, expected answers, generated output, excluded paths, or private data.
- Unknown, duplicated, malformed, mismatched, or unsupported evidence IDs require correction or
  abstention.

Deterministic application code renders canonical links from validated evidence after model output. A
plausible link is not a valid citation.
